# JJtorio

A work in progress space overhaul for Factorio 2.0. Endless procedural worlds, a
light early game, depth in space. Standalone, not compatible with Space Age or
Space Exploration.

The four planning docs live at the root.
brainstorm.md, the idea and why.
planning.md, the plan, milestones, and versioning.
infrastructure.md, how it is built.
progress-report.md, the live status.

Coordination and design notes are in team-coordination/. The mod is in mod/, dev
scripts in tools/.

Community and feedback. Join the Discord: https://discord.gg/TXseAQkgv, or email
jjtmcmultiversal@gmail.com with the subject JJtorio.
